About Volume Shader

An independent, transparent browser-based GPU shader benchmark.

What it is

A free tool and guide for testing GPU shader performance in your browser. It was built as an independent implementation inspired by the original VSBM, to make the idea easier to understand with clear explanations and published methodology.

Relationship to the original VSBM

This is not the original and is not affiliated with its author, cznull. The original is at cznull.github.io/vsbm. The scene, workload and scoring here are different, so scores must not be compared.

Methodology and versions

Everything the benchmark does is documented on the methodology page. Each result shows a benchmark version, and workload changes will be listed in the changelog there.

Source code and bugs

The site is hosted on GitHub Pages, so its source is available in the repository: View source on GitHub. Report bugs or wrong results through the repository's Issues page, and include your browser, device and the JSON result.
