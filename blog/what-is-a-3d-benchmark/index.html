What Is a 3D Benchmark? A Simple Guide for Beginners

Updated 2026-11-14 · 8 min read · by the VolumeShader team

A 3D benchmark makes your graphics card draw the same demanding 3D scene again and again, and then measures how well it did. This guide explains in plain words what a 3D benchmark measures, how to read the scores, and how to run a fair test on a PC, Mac or phone.

What is a 3D benchmark?

A 3D benchmark is a program or web page that draws a fixed 3D scene and records how fast the graphics card (GPU) can do it. The scene is the same every time. That is the whole point: because nothing changes, you can compare the result with your own earlier runs, or with another device that ran the same test.

You can think of it as a stopwatch for graphics. Instead of a time, you get numbers such as frames per second and a score.

People run a 3D benchmark for a few common reasons:

  • to check a new PC, laptop or phone as a quick graphics card test
  • to see whether a driver update or a settings change made a difference
  • to compare two devices that look similar on paper
  • to find out if a computer is slower than it should be

What a 3D benchmark measures

Most tests show the same few numbers. Once you know them, any benchmark report becomes easy to read.

  • FPS (frames per second): how many pictures the GPU draws each second. A higher number means smoother motion.
  • Frame time: how many milliseconds one frame takes. At 60 FPS each frame takes about 16.7 ms. Frame time shows if the speed is steady or jumpy.
  • 1% low FPS: the speed of the slowest frames. If the average is high but the 1% low is poor, the motion will feel like it stutters.
  • Score: one number that sums up the run. It makes comparing easy, but every tool builds its score in its own way.

If a term is new to you, the GPU glossary explains it in a few lines.

The main types of 3D benchmarks

Not all benchmarks work the same way. These are the three kinds you will meet most often.

  • Synthetic benchmarks. These use a scene made only for testing. They are repeatable and easy to compare. Well known examples that you install are 3DMark and the Unigine benchmarks.
  • Game benchmarks. Some games have a built in benchmark mode. They show how that one game runs on your device, but they say little about other games.
  • Browser based benchmarks. These run inside a web page using WebGL, so there is nothing to download. They are quick and easy, and they work on phones too. Volume Shader BM on this site is this kind of test.

No type is better in every case. An installed tool can go deeper. A browser test is faster to start and good for a quick check.

How a 3D benchmark test works

The steps are almost always the same:

  1. The test loads its scene.
  2. A short warm up runs first, so that start up work does not affect the result.
  3. The scene plays for a fixed time while the test records the time of every frame.
  4. At the end, the test turns those frame times into the average FPS, the 1% low and a score.

The 20 second benchmark on this site follows this pattern. It draws a 3D fractal with raymarching, leaves out the warm up from the result, and then shows a score card. If you are curious why that scene is so demanding, read our simple guide to volumetric shaders and raymarching.

How to read 3D benchmark scores

A score is only useful when you compare it in a fair way. Keep these points in mind.

  • Higher is better, but only when you compare the same test with the same settings.
  • Resolution matters. A run at a low resolution is easier for the GPU than a run at a high one, so the two scores cannot be compared.
  • Scores from different tools do not match. A number from one benchmark has no direct link to a number from another.
  • Small differences are normal. Two runs on the same device can differ by a few percent. Run the test two or three times and look at the pattern.
  • Look at the 1% low, not only the average. It tells you how smooth the run really felt.
  • Compare with similar devices. A phone should be compared with phones, and a laptop with laptops.

Our score card also shows a tier from S to F. It is only a quick label to help you place the result. The FPS numbers matter more. For rough reference ranges, see the score comparison page, which uses estimates and should only guide you.

What changes your result

When a score looks lower than expected, the cause is often not the GPU itself. These are the usual reasons.

  • Hardware acceleration is off. In a browser test the page may be drawn by the CPU instead of the GPU.
  • Power mode. Battery saver or an unplugged laptop can limit the GPU.
  • Heat. A hot device slows itself down. This is called throttling, and it can lower the score on a long run.
  • Old drivers. They can cause low speed or crashes.
  • Background apps. Video calls, streams and many open tabs share the GPU with the test.
  • The screen refresh rate. A 60 Hz screen usually caps the FPS at 60, even if the GPU could do more.
  • The wrong GPU. Some laptops have two GPUs, and the test may run on the weaker one.

How to run a fair test

  1. Close other apps and extra browser tabs.
  2. Plug in a laptop and turn off battery saver.
  3. Let a hot device cool down for a few minutes.
  4. Pick one resolution and keep it for every run you want to compare.
  5. Use the same browser each time.
  6. Run the test at least twice and note the average FPS and the 1% low.
  7. Save or copy the score card so you can compare later.

Benchmark or stress test?

The two are related but they answer different questions.

  • A benchmark is short. It asks, "How fast is this GPU right now?" and gives you a score to compare.
  • A stress test is longer. It asks, "Does this GPU stay stable and keep its speed when it gets hot?"

A good habit is to run the benchmark first, and then a stress test if you want to check stability. Our GPU stress test guide explains how long to run it and when to stop.

What a benchmark cannot tell you

  • It cannot tell you how every game will run. Games use many different effects.
  • A browser test cannot read the GPU temperature, fan speed or clock speed, because web pages are not allowed to read those sensors.
  • One score cannot describe everything. Look at the FPS, the frame time and the 1% low together.
  • Results from a browser test and from an installed tool are different measurements, even on the same device.

Treat a benchmark as a useful check and a way to compare, not as a final verdict on your hardware.

Frequently asked questions

What is a 3D benchmark?+

A 3D benchmark is a test that draws the same 3D scene on your device and measures how fast the graphics card can do it. The result is shown as FPS, frame time, 1% low and often a score.

What is a good 3D benchmark score?+

It depends on the test, the resolution and the device. A score is only meaningful when you compare it with the same test and settings, ideally on similar hardware. A smooth average FPS with a steady 1% low is a good sign on any test.

Is it safe to run a 3D benchmark?+

A short benchmark is safe on a healthy device, because GPUs slow themselves down when they get hot. Be more careful with long runs on phones, thin laptops and computers with dusty vents.

What is the difference between a benchmark and a stress test?+

A benchmark is short and measures speed. A stress test runs longer and checks whether the GPU stays stable and keeps its speed as it heats up.

Can I run a 3D benchmark in my browser?+

Yes. A browser based test uses WebGL, so there is nothing to install. You need a browser with hardware acceleration turned on for a fair result.

Why is my score different from someone else’s?+

Different resolution, browser, power mode, driver, heat or even the screen refresh rate can change the result. Compare scores only when the test and the settings are the same.
