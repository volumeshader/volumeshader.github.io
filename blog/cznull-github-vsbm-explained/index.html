cznull, cznull.github.io/vsbm and the Original volumeshader_bm Page

Why people search for cznull and vsbm

If you came here by searching for cznull, cznull github, cznull.github.io/vsbm, cz null test or vsbm, you are looking for the same thing: a small public web page that renders a 3D fractal with a heavy shader. People use it to test how fast a phone or computer can draw it. Some also search for it with the Chinese words 毒蘑菇 (which means poisonous mushroom) together with the word github. We do not know exactly how that nickname started, but the glowing fractal does look a little like a mushroom cap.

The name cznull is the username of the developer whose GitHub Pages site hosts the original page. The page itself is called volumeshader_bm, which is why the same test appears under so many spellings.

What the original page is

The original is a single web page on the GitHub Pages site of cznull, at cznull.github.io/vsbm. When we opened it while preparing this post, the page title was volumeshader_bm, and the page showed a plain canvas with a small configuration panel with apply and cancel buttons. Part of the text on the page is in Chinese. It is a simple page. It does not have a score card, an FPS history or explanations, and it does not try to look like a product.

That simplicity is part of the reason the test spread. The page is small, loads fast, and the scene is heavy enough to separate fast GPUs from slow ones. You can see the original code in the public repository at github.com/cznull/cznull.github.io.

We have not talked to the author, and we cannot speak for them. If something on this page about the original is wrong, please tell us and we will correct it.

How this site relates to the original

This site is an independent project. It is not run by cznull and it is not an official copy. What it does:

  • It uses the same style of scene, a Mandelbulb fractal drawn with raymarching in a fragment shader, and credits the original idea.
  • It adds a live HUD with FPS, frame time, average FPS and 1% low FPS.
  • It adds a timed 20 second benchmark with a score card you can copy or save as an image.
  • It adds a stress test page, a WebGL diagnostics page and a Shader Lab where you can edit the formula.
  • It adds plain language guides, a glossary and a troubleshooting page.

If you want the plain original experience, use the original link. If you want measurements, saved results and explanations, use this site. Both draw the same kind of picture.

Many sites use the same name. How to tell them apart

If you search for volumeshader_bm, you will find several websites with names such as volumeshaderbm, volume shader or volumeshader.pro. Some of them are test pages, some are guides, and some mix both. Here is a simple way to stay safe and informed.

  • Look at the address. The original page is on cznull.github.io. A site on another domain is not the original, even if it uses the same name.
  • Be careful with claims of being official. A site that says it is official should be able to show a clear link to the original author.
  • Never install anything to run a browser test. A real WebGL test runs in the page. A download is not needed.
  • Do not enter personal data. A benchmark has no reason to ask for your email or a password.
  • Do not compare scores between sites. Each site has its own scene settings and score formula.

How to run the test on this site

  1. Open the home page.
  2. Press start on the canvas. A glowing fractal appears and the FPS counter begins.
  3. Choose a resolution. Use 512 for an old phone and 1024 for the normal comparison.
  4. Press the 20 second benchmark button to get the score card.

Frequently asked questions

What is cznull?+

cznull is the GitHub username of the developer who hosts the original volumeshader_bm test page on GitHub Pages. People search for the name because they want to find that page.

What is cznull.github.io/vsbm?+

It is the address of the original volumeshader_bm page. It renders a 3D Mandelbulb fractal with a heavy fragment shader, and people use it to test GPU performance.

Is volumeshaderbm.com or volumeshader.pro the original?+

The original page is on cznull.github.io. Websites on other domains are separate projects. They may be useful, but they should not be treated as the original unless they clearly show a link to the author.

Is this site the same as the original?+

No. This site is an independent project that uses the same kind of scene and adds a HUD, a timed benchmark, a stress test, diagnostics and guides. It is not run by the original author.

Why is the page called volumeshader_bm?+

The name describes the method, a volume shader, and BM is usually read as benchmark. It is the title used by the original page.

What does 毒蘑菇 mean?+

It is Chinese for poisonous mushroom. People use it as a nickname when they search for this test together with github. The fractal looks a bit like a mushroom, but we do not know the exact origin of the nickname.

Can I compare my score here with a score from the original page?+

No. The original page does not give a score like this site does, and the settings differ. Compare only results made on the same page with the same settings.
