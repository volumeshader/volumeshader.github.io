WebGL guide

WebGL GPU test guide

WebGL puts GPU-accelerated graphics inside the browser, which makes an online GPU test possible without a native graphics application. It also introduces browser- and driver-level variables that can affect results.

WebGL and the GPU

The browser creates a WebGL graphics context, uploads the shader program and asks the graphics stack to render each frame.

Hardware acceleration

When the normal GPU path is available, WebGL can use the device graphics hardware. Restricted or software rendering can produce very different performance.

WebGL2 and WebGL1

Volume Shader BM prefers WebGL2 and uses WebGL1 when necessary. Record the API when comparing different environments.

Why the same GPU can score differently

Operating system, browser version, driver, resolution, refresh rate, temperature and background workloads can all affect the observed frame timing.

Making browser tests repeatable

Use the same browser, preset, duration and power state. Close competing workloads and repeat surprising results.
