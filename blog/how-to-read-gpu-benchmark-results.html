How to read GPU benchmark results

A benchmark result is more useful when you understand what each number means. Average FPS shows broad throughput, while low-frame metrics and stability help reveal uneven rendering.

Average FPS

Average FPS is a summary of the measured frame times. Higher usually means the selected shader workload was completed faster, provided the test is not capped by display synchronization.

1% low

The 1% low summarizes the slowest 1% of frame times. It can make occasional stutters easier to spot than an average alone.

Minimum and maximum

Minimum FPS is sensitive to a single long frame. Maximum FPS can be sensitive to a short frame. Use both as supporting context rather than the headline score.

Stability

Volume Shader BM defines stability from the variation of frame times. It is useful inside this benchmark, but it is not an industry-standard GPU score.

Look for patterns

Repeatable averages and similar low-frame behavior across runs are more informative than one unusually high or low number.
