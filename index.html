What is a Volume Shader test?

A volume shader test uses GPU shader code to render a three-dimensional scene made from a sampled volume rather than a conventional flat image. Volume Shader BM uses ray marching and a Mandelbulb-style fractal workload to create a repeatable fragment-shader test in your browser.

The goal is simple: give your GPU a known graphics workload, measure how quickly frames are produced, and make repeated tests easier to compare. Because this is one specific shader workload, the result should be treated as a workload score rather than a universal rating for every game or application.

How to get a useful benchmark result

Before

Prepare the device

Close heavy apps and extra tabs. On laptops, use the same power mode for every comparison. On phones, avoid testing immediately after heavy gaming or charging if temperature is high.

Run

Use Standard first

Standard is the recommended baseline. Run for 30 seconds when you need a quick result; use a longer run when you are specifically checking sustained behavior.

Compare

Hold conditions steady

Use the same preset and benchmark version. Browser version, refresh rate, resolution, power state, temperature and hardware acceleration can change the observed FPS.

Interpret

Look beyond average FPS

A high average with weak low-frame behavior can feel less smooth. A flat value near 60 or 120 FPS can also indicate display synchronization rather than raw GPU headroom.

What Volume Shader BM measures

Shader throughput

Each rendered pixel executes a fragment shader that performs ray construction, volume sampling, fractal iterations and accumulation.

Frame-time behavior

The benchmark stores frame-time samples during the measured period and derives average FPS, 1% low, minimum/maximum FPS and a stability score.

Not a game benchmark

Game engines use different APIs, shaders, geometry, CPU workloads, assets and rendering paths. A shader score should not be read as a guaranteed game FPS.

Not a VRAM diagnostic

This is not a dedicated VRAM capacity, memory-error or hardware-validation tool. Use specialized diagnostics when you need those tests.

Understanding FPS and 1% low

Average FPS

The main throughput metric. Higher usually means the browser produced frames faster under the selected shader workload.

1% low

The average frame rate represented by the slowest 1% of measured frames. It is useful for spotting uneven frame pacing.

Minimum FPS

The slowest measured frame converted to FPS. It can be sensitive to a single stall, so use it alongside the other metrics.

Stability

A benchmark-specific frame-time consistency score from 0–100. It is a companion metric, not an industry-wide GPU rating.

Technical overview

The renderer draws a full-screen triangle and runs the heavy work in the fragment shader. For each pixel, the shader constructs a camera ray, intersects a bounded volume, samples along the ray and evaluates a power-8 Mandelbulb-style function. The sampled density is accumulated into the final image.

Frequently asked questions

Is this the original VSBM?

No. Volume Shader BM on this domain is an independent implementation inspired by the original VSBM concept. The name and workload should not be treated as proof of affiliation or identical results.

Can I use it to test my GPU online?

Yes. The benchmark runs in a WebGL-capable browser and gives you live FPS plus summary metrics without requiring a native installer.

Why is my FPS stuck at 60 or 120?

Browser rendering can synchronize with display refresh. A flat result near a common refresh rate can mean the test is display-limited.

Is it safe to run?

Heavy shader workloads can increase temperature and trigger throttling. Stop the test if a device becomes excessively hot, unstable or unresponsive.
