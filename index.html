Understanding Volume Shader BM: Architecture, Mathematics & GPU Compute Stress

Volume Shader BM (commonly queried as volumeshader_bm, volume shader bm, or the viral "Toxic Mushroom" / 毒蘑菇 benchmark) is an interactive, zero-install graphical test created to measure pure floating-point arithmetic performance on graphics processors. Unlike traditional 3D benchmarks (such as 3DMark or Heaven) that evaluate polygon throughput, geometry tessellation, and texture memory bandwidth, Volume Shader BM renders a single 2D quad covering the viewport and executes thousands of raymarching steps inside a single fragment shader.

The Mandelbulb Mathematical Kernel

The visual center of the benchmark is an 8th-order 3D Mandelbulb fractal. Every light ray originating from the virtual camera marches through space via the following iterative kernel equation:

float kernal(vec3 ver) { vec3 a = ver; float b, c, d, e; for (int i = 0; i < 5; i++) { b = length(a); c = atan(a.y, a.x) * 8.0; e = 1.0 / b; d = acos(a.z / b) * 8.0; b = pow(b, 8.0); a = vec3(b * sin(d) * cos(c), b * sin(d) * sin(c), b * cos(d)) + ver; if (b > 6.0) break; } return 4.0 - a.x * a.x - a.y * a.y - a.z * a.z; }

Notice the intensity of mathematical operations: within each loop iteration, the GPU must evaluate atan(), acos(), pow(b, 8.0), sin(), and cos(). In typical 3D game engines, trigonometric functions are utilized sparingly because they require specialized transcendent execution units inside the GPU's Special Function Units (SFUs). By forcing up to 1,000 ray steps per pixel with five trigonometric iterations per step, Volume Shader BM completely saturates GPU ALU compute registers without relying on memory bandwidth.

Why Frame Times & 1% Lows Matter More Than Peak FPS

Many users look exclusively at instantaneous FPS, but frame time consistency reveals the true health of the graphics driver and thermal cooling solution. When an integrated mobile GPU or ultrabook heats up, thermal management firmware downclocks GPU frequencies. This causes micro-stutters where single frames take 50ms to 100ms to render, even while the average FPS appears acceptable. Volume Shader BM measures the 1% Low FPS (the 99th percentile slowest frame times) to reveal micro-stuttering and thermal throttling.
