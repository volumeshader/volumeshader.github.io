What is Volume Shader BM?

Volume Shader BM, also written as volumeshader_bm, volume shader bm or VSBM, is a free test that checks how fast your graphics card can do heavy math. It runs inside your browser, so there is nothing to download. When you press start, the page draws a glowing 3D fractal called a Mandelbulb and counts how many frames per second your device can produce.

Most 3D benchmarks measure how many triangles a GPU can draw. This one does not use triangles at all. The whole picture is made by one program, called a fragment shader, that runs for every pixel. Each pixel sends a ray into 3D space and asks a formula whether the ray hit the shape. That method is called raymarching, and it is very demanding, because it repeats a long calculation many times for every pixel.

This makes the test good for quick checks. You can see if a new phone is fast, compare two laptops, find out whether your browser is really using your GPU, and watch whether performance drops when the device gets hot.

How to use the test

  1. Press the start button on the canvas. The fractal appears and the live numbers begin.
  2. Choose a resolution. 512 is light, 720 is medium, 1024 is the normal comparison size and 1440 is heavy.
  3. Choose a preset. Mandelbulb is the classic scene. The other presets use the same method with a different formula.
  4. Use Auto-Rotate and Reset View to look at the shape from different sides. Pause and resume whenever you like.
  5. Press Run 20s Benchmark when you want a result to keep. The page ignores the first two seconds, records the rest and shows a score card.
  6. Copy the summary or download the card as an image to compare later.

What the numbers mean

FPS is how many frames the GPU finishes each second. Frame time is how many milliseconds one frame takes. 60 FPS is about 16.7 ms and 30 FPS is about 33 ms. Average FPS shows the overall speed during the run. 1% low FPS shows how slow the worst moments were, which reveals stutter that the average hides.

The score combines these: average FPS times 8.5, plus 1% low FPS times 4.5, multiplied by a resolution factor. The tier is then set from the score.

Why this scene is hard for a GPU

The shape is defined by a short function. For every step along every ray, the shader runs that function. Inside it, a loop repeats up to five times and uses sine, cosine, arc tangent, arc cosine and a power function. These functions are slower on a GPU than simple addition and multiplication.

float kernal(vec3 ver) { vec3 a = ver; float b, c, d, e; for (int i = 0; i < 5; i++) { b = length(a); c = atan(a.y, a.x) * 8.0; e = 1.0 / b; d = acos(a.z / b) * 8.0; b = pow(b, 8.0); a = vec3(b * sin(d) * cos(c), b * sin(d) * sin(c), b * cos(d)) + ver; if (b > 6.0) break; } return 4.0 - a.x * a.x - a.y * a.y - a.z * a.z; }

A single ray can take up to about one thousand steps. At 1024 by 1024 there are more than a million rays. The worst case adds up to billions of loops for one frame. Because the scene hardly reads any memory, the speed depends almost only on how fast the shader cores can calculate. If you want the full explanation in simple words, read volumetric shaders and raymarching explained.

Tips for a fair result

  • Plug in a laptop and turn off battery saver on phones.
  • Close other tabs, videos and games.
  • Use the same browser, the same resolution and the same preset when you compare devices.
  • Run the benchmark twice. If the numbers are close, you can trust them.
  • Let a hot device cool down before you test.
  • If FPS stays at exactly 60, raise the resolution.

What the test cannot measure

This is not a game benchmark. It does not test video memory, textures, the CPU or ray tracing hardware. It cannot read the GPU temperature or clock speed, because a web page is not allowed to see them. It gives one useful piece of information, which is how fast your device does heavy shader math and how stable that speed is. Use it together with real games or other tools if you need a complete picture.

Frequently asked questions

What is Volume Shader BM (volumeshader_bm)?+

It is a browser test that draws a 3D Mandelbulb fractal with a heavy WebGL shader and measures how fast your GPU can do it. The result is shown as FPS, frame time, 1% low FPS and a score. It is also written as volumeshader bm, volumeshaderbm or VSBM.

What does BM stand for?+

BM is most commonly read as benchmark. The short form is informal, but it fits what the test does.

Is this the original cznull page?+

No. This is an independent site that uses the same kind of scene and adds a HUD, a timed benchmark, a stress test and guides. The original page is hosted at cznull.github.io/vsbm. Read our explainer to see how the two relate.

Is it safe to run on my phone?+

Short runs are fine on a cool phone that is not charging. The test uses the GPU heavily, so the phone will warm up. Use the 512 or 720 resolution, keep runs short and stop if the phone becomes too hot to hold.

Why is my FPS stuck at 60?+

Browsers do not draw faster than your screen refresh rate. If your screen is 60 Hz, the FPS cannot go above 60. Raise the resolution until the number falls below the cap and you will see real differences.

How is the score calculated?+

The score is (average FPS x 8.5 + 1% low FPS x 4.5) x a resolution factor. The factor is 0.6 at 512, 0.85 at 720, 1.0 at 1024 and 1.4 at 1440. A steady device scores higher than a stuttering one with the same average FPS.

Which resolution should I choose?+

Use 1024 by 1024 for normal comparisons. Choose 512 for older phones and weak integrated graphics, 720 for most phones and thin laptops, and 1440 for strong desktop GPUs.

Can I test in different browsers?+

Yes. Chrome, Edge, Firefox and Safari all run WebGL through different graphics layers, so results can differ a little on the same device. Use the same browser when you compare two devices.

Why is my FPS very low on a good computer?+

Usually the browser is not using the GPU. Turn on hardware acceleration, update the graphics driver, plug in a laptop and close other tabs. See the troubleshooting page for more.

Does the test show my GPU temperature?+

No. Web pages cannot read temperature, fan speed or clock speed. You can only see the effect of heat, which is an FPS drop over time. Use the stress test to watch for that.
