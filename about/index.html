About VolumeShader BM

VolumeShader BM is dedicated to delivering transparent, accessible, and privacy-preserving graphics benchmarking through pure web standards.

Our Core Philosophy

  • Tool-First Utility: Immediate interactive functionality on every page. No paywalls, no software installers, and no bloated downloads.
  • 100% Client-Side Privacy: Zero server telemetry, zero analytics trackers, and zero fingerprinting. All calculations occur inside your local GPU hardware.
  • Open Attribution: We proudly attribute the foundational 3D Mandelbulb raymarching kernel to developer cznull (cznull/cznull.github.io), who popularized the demonstration on Bilibili and GitHub.

Hosting on GitHub Pages

The site is deployed statically via GitHub Pages at volumeshader.github.io. This ensures zero hosting latency, global edge caching via fast CDN nodes, and 100% verifiable source code.
