GPU and WebGL Benchmark Glossary

Short, plain definitions of the words you meet when you test a GPU in the browser, from FPS and 1% low to raymarching, shaders and throttling.

Raymarching

A way of drawing a shape by moving a ray forward in small steps and asking a formula at each step whether it has hit something.

Mandelbulb

A 3D shape related to the Mandelbrot set, made by repeating a formula with spherical coordinates and a power. The main scene of this test is an 8th order Mandelbulb.

Fractal

A shape that keeps showing new detail the closer you look at it.

Shader

A small program that runs on the GPU and decides how things are drawn.

Fragment shader

A shader that runs once for every pixel (fragment) being drawn. The whole volume shader scene runs inside one fragment shader.

GLSL

The language used to write shaders for WebGL and OpenGL.

Volume shader

A common name for a shader that draws a 3D shape or density by marching rays through space. Also called a volumetric shader.

WebGL

The web standard that lets a page use the GPU to draw 3D graphics in the browser.

WebGPU

A newer web graphics interface designed to replace WebGL over time. This test uses WebGL.

GPU

The graphics processor. It has thousands of small cores that do many calculations at the same time.

ALU

Arithmetic logic unit. The part of a GPU core that does the math, such as adding, multiplying and sine.

FPS

Frames per second. How many pictures the GPU finishes each second. Higher is smoother.

Frame time

How many milliseconds one frame takes. 60 FPS is about 16.7 ms.

Average FPS

The overall speed during a run.

1% low FPS

The speed of the slowest 1% of frames, worked out from the frame time that 99% of frames beat. It shows stutter that the average hides.

Stutter

Short pauses or uneven frame times that make motion look rough even when the average FPS is high.

Benchmark

A repeatable test that gives a number you can compare with other results.

Stress test

A test that keeps the hardware under heavy load for longer, to check stability and heat.

Warm up

The first moments of a run. They are often slower because the shader is compiling and the GPU is waking up, so this site ignores the first two seconds of the 20 second benchmark.

Score and tier

The combined number and letter shown after a benchmark. The score uses average FPS, 1% low FPS and a resolution factor.

Thermal throttling

When a chip lowers its own speed to stay cool. It shows up as an FPS drop over time.

Hardware acceleration

A browser setting that lets the GPU draw graphics. When it is off, the CPU does the work and speed is very low.

Software rendering

Drawing graphics with the CPU instead of the GPU. Names such as SwiftShader and llvmpipe point to it.

ANGLE

A layer in Chrome and Edge that turns WebGL calls into the native graphics system of the computer, such as Direct3D, Metal or Vulkan.

Context lost

A WebGL event that happens when the system resets the graphics connection, for example after a driver reset.

Driver

The software that lets the operating system and the browser talk to the GPU.

TDR

Timeout Detection and Recovery. A Windows feature that resets the graphics driver when the GPU takes too long on one task.

highp

A shader precision setting for full precision decimal numbers. Fractal math needs it to avoid visible errors.

Resolution

The size of the canvas in pixels. Doubling the width and height means four times as many pixels to calculate.

Refresh rate

How many times per second the screen updates. Browsers do not draw faster than this, so it caps FPS.

VRAM

Video memory on a graphics card. This test uses very little of it.

Normal vector

The direction a surface faces. It is needed to calculate light. In raymarching it is found by sampling the formula around the hit point.

Distance estimator

A function that tells how far a point is from a shape. Many raymarchers use one to take bigger safe steps.

Frequently asked questions

What is the difference between FPS and frame time?+

FPS counts frames per second, and frame time is the time one frame takes. They show the same speed in two ways. Frame time is better for spotting stutter.

What is the difference between WebGL and WebGPU?+

WebGL is the long standing web graphics interface and works almost everywhere. WebGPU is newer and more modern, and it is still being adopted by browsers.

Which terms should a beginner learn first?+

Start with FPS, frame time, 1% low FPS, resolution and thermal throttling. They explain most of what the test shows. Then read what Volume Shader BM is.
