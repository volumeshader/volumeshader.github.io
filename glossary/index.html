GPU & WebGL Benchmark Glossary

Authoritative definitions of key graphics rendering, shader math, and hardware benchmarking terminology.

Raymarching

A volumetric rendering technique where light rays are stepped through 3D space in discrete intervals to find surface intersections using mathematical distance functions rather than polygon meshes.

Mandelbulb

A three-dimensional analogue of the Mandelbrot set fractal constructed using spherical coordinates and powers of complex 3D vectors. VolumeShader BM uses an 8th-order Mandelbulb.

1% Low FPS

The average framerate of the slowest 1% of frames rendered during a benchmark. This metric captures micro-stutters and driver stalls that average FPS calculations hide.

Thermal Throttling

An automated hardware safety mechanism where GPU and CPU clock speeds are reduced to dissipate excess heat when silicon temperatures reach safety thresholds.

ALU (Arithmetic Logic Unit)

The fundamental processing unit inside a GPU shader core responsible for computing floating-point operations (additions, multiplications, trigonometric functions).

WebGL Context Lost

An event triggered when the browser or operating system resets the graphics hardware context due to a shader timeout, driver crash, or device power state transition.

Highp Precision

In GLSL shaders, highp specifies full 32-bit floating-point precision, ensuring accurate rendering of complex fractal coordinates without rounding artifacts.

ANGLE (Almost Native GLES)

Google's translation layer inside Chromium that converts WebGL API calls into native desktop graphics APIs such as Direct3D 11, Metal, or Vulkan.

VolumeShader BM

A modern, browser-first WebGL volumetric raymarching benchmark and GPU stress testing platform. Built on the authoritative Mandelbulb raymarching kernel originally conceived by cznull.
