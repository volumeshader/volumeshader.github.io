Privacy policy

Short version: the test runs on your device and this site does not collect your results.

What runs where

The benchmark runs locally in your browser. Results are shown to you and are not sent to a server by this site.

What the page reads

To show what is being tested, the page reads your graphics adapter name, WebGL version, screen size and pixel ratio. This stays in your browser.

Hosting

The site is hosted on GitHub Pages. GitHub may keep standard server logs under its own policy. If you add analytics or ads later, update this page to describe them.

Contact

If you need to contact the site owner, use the contact method provided with the site or GitHub repository.
