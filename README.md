# Volume Shader BM – Traffic & Content Upgrade

This package keeps the browser benchmark engine and expands the content architecture around the highest-value keyword clusters from the supplied research.

## Deploy
Upload the contents of this folder to the GitHub Pages repository for `https://volumeshader.github.io/`. The canonical URLs in the HTML and sitemap already use that domain.

## Main pages
- `index.html` – primary Volume Shader BM tool and core topic
- `gpu-benchmark.html` – online GPU benchmark
- `pc-stress-test.html` – PC / GPU load testing
- `3d-benchmark.html` – 3D benchmark intent
- `graphics-test.html` – graphics/video-card testing
- `phone-gpu-test.html` – phone GPU testing
- `webgl-benchmark.html` – WebGL benchmark intent
- `gpu-load-test.html` – GPU load testing
- `shader-test.html` – shader test intent
- `how-to-test-gpu.html` – how-to search intent
- `blog/` – long-form supporting guides

## Ads
The pages include labeled ad placeholders. Replace only those placeholders with your approved ad-network code after you have the required publisher/account information. Do not add a fixed banner over the benchmark controls or use popups that block the test.

## Important
Keep the benchmark version visible. When changing the shader workload or formulas, increment the benchmark version and update the methodology page so old and new results remain distinguishable.
