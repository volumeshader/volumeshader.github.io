Why scores cannot be mixed across levels

An Extreme score is not simply a “better” Standard score. The workloads are intentionally different. When comparing hardware, keep the preset fixed and record the benchmark version alongside the result.

Which level should I use?

Most users

Start with Standard for a balanced workload.

Older hardware

Start with Simple so the device can complete a useful run.

Fast desktop GPU

Try Advanced when Standard hits a display ceiling.

Very heavy testing

Use Extreme only when you understand the extra load and heat.
