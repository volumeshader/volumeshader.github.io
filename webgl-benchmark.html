WebGL benchmark: what a browser GPU test measures

A WebGL benchmark runs a graphics program inside your browser and counts how fast your GPU finishes it. It is quick and easy, but it measures a specific thing.

How the test works

The page draws one rectangle that covers the screen. A fragment shader then runs once for every pixel. Each pixel fires a ray into a 3D fractal and moves it forward in steps (ray marching) until it hits the surface. More pixels, more steps and more fractal iterations mean more work.

What it measures well

  • Shader math speed (sin, cos, powers, loops).
  • Fill rate at the chosen resolution.
  • Sustained speed as the device warms up.

What it does not measure

  • Video memory size or bandwidth in depth.
  • Game engine performance, textures or geometry load.
  • Hardware ray tracing cores. Ray marching is done in a normal shader.
  • Native API speed (DirectX, Vulkan, Metal).

WebGL, WebGL2 and WebGPU

WebGL 1 and 2 are widely supported. WebGPU is newer and can run the same math with less overhead, so the same device may score differently on each. This test uses WebGL2 when available and falls back to WebGL1.

Browser and driver effects

The browser translates shaders for your driver, and each browser does this a little differently. Compare scores only on the same browser and settings.
