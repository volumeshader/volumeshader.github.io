Browser graphics API

WebGL benchmark online

A WebGL benchmark measures how your browser and graphics stack execute a GPU workload. Volume Shader BM uses WebGL because it can run the same style of shader test without a native installer.

Run the WebGL GPU test

The benchmark prefers WebGL2 and falls back to WebGL1 when needed. If you are looking for an OpenGL test, note that WebGL is a browser API with its own graphics stack and should not be treated as a direct desktop OpenGL benchmark. Your environment line reports the graphics API used and, where the browser exposes it, the renderer name.

Why browser GPU scores can differ

Hardware acceleration: a browser may use software rendering or restricted graphics when acceleration is unavailable.
Driver stack: the same GPU model can behave differently across operating systems and driver versions.
Refresh synchronization: a display-linked frame scheduler can cap an otherwise faster workload.
Resolution: rendering more pixels increases shader work.

Is WebGL the same as OpenGL?

WebGL is a JavaScript graphics API for browsers built around the OpenGL ES ecosystem. A WebGL benchmark therefore should not be treated as a direct desktop OpenGL application benchmark. It is a browser graphics test with its own runtime, driver and scheduling behavior.

When the benchmark will not run

If the browser cannot create a WebGL context or the shader fails to compile, the benchmark cannot measure GPU performance. Try a current browser, confirm hardware acceleration is available and avoid remote-desktop environments that disable normal GPU access.
