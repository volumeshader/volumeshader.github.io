What does an online GPU benchmark measure?

This benchmark primarily measures how efficiently the browser executes the selected fragment-shader workload. That includes repeated arithmetic in the fractal function, ray marching through the volume and final color accumulation.

How to benchmark a GPU consistently

  1. Use the same benchmark version and preset.
  2. Use the same browser when comparing repeated runs.
  3. Keep power mode, resolution and display refresh conditions similar.
  4. Close background workloads that can steal CPU or GPU time.
  5. Repeat the test when a result looks unusual rather than treating one run as a final diagnosis.
