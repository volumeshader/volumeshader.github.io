How the shape function works

The raymarching engine asks the function float kernal(vec3 ver) one question many times: "Is this point in space inside the shape?" The function answers with a number. A positive number means inside, and a negative number means outside. The ray moves forward in small steps. When the answer changes from negative to positive, the surface is somewhere between the last two steps.

After that, a short search narrows down the exact surface point. The engine then asks the function a few more questions around that point, to find which way the surface faces, and uses that direction for light and color. You only have to write the shape. The rest is done for you.

Things to try

  • Change the power. The number 8.0 in the Mandelbulb formula is its power. Try 4.0 or 12.0 and see how the lobes change.
  • Change the loop count. Fewer loops give a smoother and faster shape. More loops add detail and cost time.
  • Load another preset. The Julia bulb, the cosine field and the twisted torus show how different formulas look with the same engine.
  • Watch the FPS. Every edit that adds math will lower it, which shows how shader cost works.

Frequently asked questions

Do I need to know GLSL to use the lab?+

No, you can load a preset and press recompile. If you want to edit, small changes such as a number in the formula are a good start.

What happens if I make a mistake?+

If the shader does not compile, an error box shows the message from the graphics driver. Fix the line it points to, or press the reset button to go back to the default code.

Which function should I edit?+

Edit the function named kernal. It receives a 3D point and returns a number. A positive number means the point is inside the shape, and a negative number means it is outside.

Can I break my computer by editing the shader?+

A very heavy formula can slow the page down or make the browser reset the graphics context. Your computer is not harmed, and a reload brings everything back.

Why is my edited shader so slow?+

Every extra loop or math function runs for every step of every pixel. Reduce the loop count or lower the resolution to speed it up.
