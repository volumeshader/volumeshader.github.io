GPU load test vs GPU stress test

The terms are often used interchangeably, but the test scope matters. Volume Shader BM is a browser-based graphics load test. It is not designed to validate every part of a GPU or memory subsystem under all conditions.

What to watch during a load test

FPS trend

A gradual drop can indicate sustained limits that do not appear in the first few seconds.

1% low

Low-frame behavior helps reveal uneven frame pacing.

Temperature

Heat can change clock speeds and therefore the observed result.

System responsiveness

Stop the test if the device becomes unstable or unusable.
