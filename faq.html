Volume Shader BM FAQ

Straight answers to the questions that matter when you run a browser GPU test and need to understand the result.

Benchmark basics

What is Volume Shader BM?

It is an independent browser-based GPU shader benchmark inspired by the original VSBM concept. It renders a fixed volume-shader workload and reports frame-rate and frame-time metrics locally.

Is Volume Shader BM affiliated with the original VSBM?

No. This implementation is independent. Because the implementations and workloads can differ, scores from different sites should not be treated as directly interchangeable.

Can I test my GPU online?

Yes. A WebGL-capable browser can run the benchmark without a native installer.

Is this a gaming benchmark?

No. It is a shader benchmark. It can show how a device handles this graphics workload, but it cannot predict performance in every game or 3D application.

FPS and results

What is a good FPS?

There is no universal “good” number because preset, display synchronization, device, browser and temperature all affect the result. Use the same conditions for comparisons.

Why is my FPS stuck at 60, 90 or 120?

The browser may synchronize rendering with your display refresh rate. A flat ceiling can mean the test is display-limited.

Why is my second run slower?

Heat, power management, background tasks or browser scheduling can change sustained performance. Repeat under the same conditions before drawing conclusions.

What does 1% low mean?

It summarizes the slowest 1% of measured frame times. It can expose uneven rendering that an average FPS number hides.

Can I compare phone and desktop results?

You can compare broad behavior, but cross-device results need extra caution because resolution, browser stack, power limits and thermals can differ substantially.

Safety and hardware questions

Is the test safe?

The software runs in the browser, but heavy graphics workloads can raise temperature and trigger throttling. Stop if the system becomes excessively hot, unstable or unresponsive.

Does it test VRAM?

Not directly. This is a shader-focused benchmark and not a dedicated VRAM capacity or memory-error diagnostic.

Can a low score prove a phone is fake?

No. A benchmark result alone cannot establish authenticity. Browser version, temperature, battery state, power mode and software settings can all affect performance.

Does the benchmark upload my result?

The benchmark calculates the metrics locally and can keep history in browser storage. It does not need to upload benchmark results to a server for the test to work.

Why did the benchmark step down?

On extremely slow devices, the benchmark can lower the workload after prolonged frame delays. The result is marked adaptive so it is clear that the requested preset was not sustained.
