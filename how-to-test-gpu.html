GPU testing guide

How to test your GPU online

You do not always need a desktop installer to get a useful first look at graphics performance. This guide shows how to use Volume Shader BM and how to avoid the common conditions that make GPU tests hard to compare.

Step 1: open the benchmark

Use a current browser with WebGL support. Open the benchmark and check that the WebGL context starts without an error.

Step 2: choose a consistent preset

Standard is the recommended starting point. Simple is useful for slower devices. Advanced and Extreme increase workload substantially.

Step 3: run for 30 seconds

For a quick GPU performance test, a 30-second run is easy to repeat. Record the average FPS, 1% low and stability rather than relying on a single live FPS reading.

Step 4: repeat the test

Run the same preset again under the same conditions. If results move significantly, check browser activity, temperature, power mode and display synchronization before drawing conclusions.

How to test a GPU on a laptop

Plug in the laptop when comparing sustained performance and keep the power profile unchanged. A battery saver mode can reduce graphics clocks. Thermal limits can also cause a score to fall during longer runs.

How to test a graphics card on a desktop PC

Close other 3D applications, overlays and GPU-heavy tabs. Use the same browser and monitor setup for repeated tests. Do not treat one web benchmark as a complete hardware diagnosis.

How to test GPU performance on a phone

Keep brightness, power state and browser consistent. Watch temperature because small devices can change clock speeds quickly during heavy graphics workloads. Stop when the phone becomes excessively hot or unstable.

How to know whether a result is believable

Repeatability: similar conditions should produce broadly similar results.
API: note whether the browser used WebGL2 or WebGL1.
Ceiling: a flat 60/90/120 FPS result may be display-limited.
Thermals: a long-run drop can be normal sustained-performance behavior.
