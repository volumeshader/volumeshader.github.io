How to test a GPU or graphics card

Testing a graphics card takes about ten minutes. You need to know which GPU you have, run a repeatable test, and read a few numbers.

1. Find out which GPU you have

On Windows open Task Manager, then Performance, then GPU. On a Mac choose About This Mac. In the browser test on this site, the renderer name appears on the screen and in the result panel. Laptops can have two GPUs; make sure the browser uses the strong one.

2. Prepare

Update drivers, close heavy programs, plug in power and set the power plan to balanced or high performance.

3. Run a benchmark

Use the Standard test: 30 seconds at Standard complexity. Write down the average FPS, the 1% low and the stability. Repeat twice more.

4. Read the numbers

  • Average FPS: overall speed.
  • 1% low FPS: how bad the worst moments are. Close to the average means smooth.
  • Frame time: 16.7 ms is 60 FPS; 33 ms is 30 FPS.
  • Stability: how even the frames are.

5. Check heat

Run the stress test and watch whether FPS drops. Use your system tools to see temperature. Most cards stay below about 85 C under load, but limits differ by model, so check your maker's figures.

6. What to do with a bad result

Update drivers, clean dust from vents, check power settings, and test in another browser. If crashes continue, test with a native tool too. See the WebGL benchmark notes for the limits of browser tests.
